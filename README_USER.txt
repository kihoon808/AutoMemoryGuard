[ 프로그램 소개 ]
AutoMemoryGuard는 16GB 이하 메모리 환경의 게이머를 위한 초경량 시스템 최적화 도구입니다.
백그라운드에서 상주하며 20MB 미만의 메모리만 사용하여 0.50ms 커널 고정밀 타이머를
동적으로 활성화하고, 게임 플레이 중 불필요한 백그라운드 프로세스를 Windows 11 EcoQoS
(효율 코어)로 격리하여 스터터링과 인풋렉을 최소화합니다.

[ Windows SmartScreen 경고 발생 시 조치 방법 ]
개인 개발자가 무료로 배포하는 오픈소스 프로그램 특성상, 유료 EV 인증서가 없어
최초 실행 시 'Windows의 PC 보호 (알 수 없는 게시자)' 파란색 경고창이 뜰 수 있습니다.
* 해결 방법:
  1. 경고창 내부의 '추가 정보' 파란색 글씨 클릭
  2. 우측 하단에 나타나는 '실행' 버튼 클릭
  * VirusTotal 70여 개 백신 진단 결과 100% 무해하며 바이러스토탈 링크는 GitHub 저장소에 투명하게 공개되어 있습니다.

[ 핵심 기능 ]
1. 0.50ms 동적 고정밀 타이머 제어 (NtSetTimerResolution)
   - 게임 실행 감지 시 0.50ms 최고 해상도로 자동 고정 (ISLC 기능 내장)
   - 게임 종료 시 Windows 기본 타이머(15.6ms)로 안전 원복하여 배터리/CPU 전력 절약
2. 안티치트 100% 안전 백그라운드 격리 (Win11 EcoQoS)
   - Riot Vanguard, Easy Anti-Cheat(EAC), BattlEye 등 게임 프로세스 핸들은 절대 건드리지 않습니다.
   - 주변 웹 브라우저(크롬, 엣지), 메신저, 블로트웨어만 효율 코어(EcoQoS)로 밀어냅니다.
3. 지능형 2단계 메모리 방패
   - 게임 실행 직후 1회 선제적 무중단 Working Set 메모리 확보
   - 게임 중에는 92.0% 임계치 도달 전까지 메모리 정리를 차단하여 인게임 프레임 드랍(스터터링) 원천 방지
4. Alt-Tab 히스테리시스 보호
   - 게임 중 잠시 바탕화면이나 웹 브라우저를 확인하더라도 게임 프로세스가 살아있는 한 게이밍 모드를 유지합니다.

[ 단축 조작법 ]
- 시스템 트레이(우측 하단)의 녹색/주황색 RAM 점유율 아이콘을 더블클릭하면 대시보드가 열립니다.
- 트레이 아이콘 우클릭 -> '게이밍 모드 (강제 On/Off)'를 통해 수동 제어가 가능합니다.
- 창을 닫아도 백그라운드 트레이에 초경량(10-15MB)으로 자동 상주합니다.
